

## Features
- **True neural activation maximization** using Inception5h
- Video & image support
- **Trippy feature visualization** ('mixed3a' layer)
- Auto-downloads model if missing

## Usage
```
cd media_ai
python deep_dream_original.py items.png          # → dreamed_image.jpg
python deep_dream_original.py video.mp4         # → dreamed_video.mp4
python deep_dream_original.py input.avi
```

## Assets
- `data/tensorflow_inception_graph.pb` (auto-download)
- `items.png` (current input)
